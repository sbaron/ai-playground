# HTML Games

Single-file browser games. Each one was created in one shot by
**Qwen3.8 27B (Q6_K_M)**, running locally.

| Game | File |
| --- | --- |
| Neon Breaker | `breaker.html` |
| Neon Void | `neon-void.html` |
| Neon Stack | `neon-stack.html` |
| Pac-Man | `pacman.html` |

Each game is a self-contained HTML file with no dependencies. Best scores are
kept in the browser's `localStorage`.
